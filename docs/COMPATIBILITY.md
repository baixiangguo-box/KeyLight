# 兼容性与边界

目前仅 WIN 60 HE 是经过实机验证的适配型号。WIN 68 HE 有专用布局与协议适配，尚未实机验收；其他协议族保持拒绝写入，识别目录不代表兼容承诺。

WIN60 HE 的可保存内置灯效会写入灯光配置并读回核对，不升级固件或改动磁轴、键位和触发参数。固件动画与软件算法可能不同；速度/亮度受固件档位限制。尚未覆盖断电重插与所有内置模式的主观效果。

AI、音频等软件动态效果依赖程序持续计算。退出时保存本地作品和设置，程序完全退出；键盘使用之前的内置设置。无法保证任意动态作品离线运行。

Windows 11 x64已有实际验证；安装器接受 Windows 10 2004及以上x64兼容环境，Windows 10/ARM64和干净虚拟机未因此获得实测结论。缺少WebView2时由微软安装器联网补齐，该干净系统分支未实测。

安装版用户数据在 `%LOCALAPPDATA%/KeyLight/data`，更新和卸载保留数据。分享码不含API Key或对话。AI请求会把近期对话、草稿和模拟预览发到用户自行配置的接口。
