# 1.7.0 验证说明

- 163项离线单元测试：输入映射、灯效、颜色与时间断言、分享、存储、HTTP校验、AI路由、同轮修复、独立复查、取消、线程限额、退出守卫与失败保留。
- 59项浏览器回归：假HID/模型替身，涵盖开屏/降级/缩放/减少动态、预设/音频/涂色/分享、AI草稿与灯光隔离、生成/修改/失败/重开/删除/取消、显式应用。
- 原生冻结程序：独立窗口、二次启动、X关闭/端口释放、重开和草稿持久化；本机模型替身验证创作HTTP链路，不打开真实HID。
- 真实配置模型：逐键松开5秒留光、A控制B开关、移动光束、分区音频，以及5秒改2秒/亮度40%的连续修改和普通讨论。原程序通过应用编译器和额外输入/像素检查；没有把模型的文字自述当作成功证据。

真实模型测试脚本初次传错渲染函数参数；修正测试脚本后，原样重绘已保存程序全部通过，未修改生成物或额外调用模型掩盖失败。真实模型、模拟模型、渲染检查和物理主观验收分别记录。

模型生成验收仍可能误解用户；有限采样与覆盖守卫不能证明任意语义和未来输入。预算耗尽或网络错误会保留旧稿，用户可以继续反馈。其他模型、其他键盘、全新系统、断电重插没有新的实测结论。
